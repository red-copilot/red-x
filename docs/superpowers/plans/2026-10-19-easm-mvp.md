# EASM MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace ARL's dashboard with an organization-first EASM wallboard that resolves domains to organizations via ICP, enriches assets with GeoIP, and overlays an asset graph from Neo4j.

**Architecture:** MongoDB is the source of truth for organizations, domain ownership, ICP evidence, IP locations, jobs, and graph outbox events. A Neo4j projector consumes the outbox; the map reads Mongo, the graph reads Neo4j. Vue 3 + ECharts renders both layers on one dark full-screen canvas at `/`.

**Tech Stack:** Go 1.27, MongoDB 8, Neo4j 5.x, Vue 3, TypeScript, Pinia, ECharts + vue-echarts, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-19-easm-mvp-design.md`

## Global Constraints

- JSON/BSON fields use camelCase; IDs use `bson.ObjectID`; timestamps use `time.Time`.
- `context.Context` is the first parameter of every new service, provider, repository, and handler method.
- MongoDB is the source of truth; Neo4j is a rebuildable projection and must never block scanning.
- ICP cookie/API keys only from environment or read-only files; never in Mongo, logs, frontend, audit detail, or Neo4j.
- No Python runtime inside ARL. ICP_Query is an external sidecar called over HTTP.
- No captcha bypass, signature forgery, or scraper fallback inside ARL.
- CDN nodes count as organization assets, marked `cdn=true`; the map states "CDN edge", never origin.
- One root domain has at most one `confirmed` organization; low confidence never auto-confirms.
- Risk = latest finding per `(asset target, dedupeKey)`; `info` excluded; unlinked findings counted separately.
- Graph queries: `depth <= 3`, `limit <= 500`; excess returns `truncated/aggregated`.
- The EASM page replaces `DashboardPage` at `/`; no `/dashboard` route is kept.
- Reuse existing RBAC/CSRF; mutations require `operator` or `admin`.
- The workspace has unrelated uncommitted scanner changes. Stage only files listed for the current task.

## Review Focus

- ICP cookie expired or ICP_Query down: page, organization list, and confirmed domains still render with an explicit degraded state.
- Shared/CDN IP: appears under every organization that resolves to it, marked shared/CDN, counted once per organization.
- Attribution: low confidence never auto-confirms; a root domain cannot have two confirmed owners simultaneously.
- Stale graph edges: removing a domain or changing an IP list removes old edges after projection and after rebuild.
- Large organizations: map/graph stay bounded; unlocated assets are counted, not plotted at fake coordinates.
