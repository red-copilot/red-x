## Plugin note

The registry contains the legacy counts: 40 POC, 28 sniffer and 28 brute plugins. HTTP checks, banner sniffing and the common brute protocols (SSH, MySQL, PostgreSQL, MSSQL, MongoDB, Redis, FTP, SMTP, IMAP, POP3 and several HTTP applications) are implemented. RDP, CobaltStrike and Shiro CBC/GCM remain registered extension points rather than complete protocol implementations.

## Deliberate differences

- No legacy MongoDB data import and no old `/api` compatibility; PostgreSQL is the only application database; `/dashboard` and `/easm/*` API/page aliases are intentionally removed.
- The console uses a direct JSON response contract with RFC 7807 problem errors instead of the old `{data: ...}` success envelope.
- OS detection is limited to the OS metadata returned by naabu service probes.
- Screenshots require a browser runtime.
- Scanner result timing and fingerprints differ from nmap/massdns; ProjectDiscovery SDKs are pinned in `go.mod`.
- Nuclei runs only the HTTP templates under `assets/nuclei`; interactsh, code, file and headless templates are disabled by default.
